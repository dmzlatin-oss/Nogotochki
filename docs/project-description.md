# Описание проекта «Ноготочки» — Сервис записи

## Общая информация
Сервис записи для бьюти-студии «Ноготочки» — веб-приложение, позволяющее клиентам бронировать услуги студии (ман licure, брови), а администратору — управлять услугами, мастерами, расписанием и записями.

## Задача
Создать сервис записи на базе существующего кода проекта «Aurelia Studio», адаптировав его под требования ТЗ для бьюти-студии «Ноготочки».

## Решение
1. **Анализ существующего проекта:** изучен кодовая база «Aurelia Studio» (React + Node.js + Express + SQLite), идентифицированы эндпоинты API, структура БД, компоненты фронтенда.
2. **Копирование проекта:** создана копия в ~/projects/nogotochki-booking/, старый проект не изменён.
3. **Адаптация данных:** заменены seed.js и данные БД на данные «Ноготочки» (6 услуг, 3 мастера, расписание, блокировки по ТЗ).
4. **Расширение API:** добавлены эндпоинты /api/blocks, /api/schedule, PATCH /api/bookings/:id для переноса записей.
5. **Запуск сервера:** backend запущен на порту 3001, API отвечает, данные отдаются.
6. **Документирование:** создана документация (CLAUDE.md, дневник сборки, отчёт о тестировании, TODO).

## Используемые технологии
- **Frontend:** React 18 + Vite + TypeScript + React Router 7 + Tailwind CSS
- **Backend:** Node.js + Express + SQLite
- **База данных:** SQLite (файл booking.db)
- **Аутентификация:** токены (Bearer), хеширование паролей (scrypt/bcrypt)

## Результаты
- Бэкенд сервиса «Ноготочки» запущен и работает на порту 3001
- API отдаёт корректные данные (6 услуг, 3 мастера, расписание, блокировки)
- База данных заполнена тестовыми данными
- Фронтенд (исходники) присутствует в проекте, требуется сборка и запуск
