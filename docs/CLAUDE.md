# Сервис записи «Ноготочки» — Паспорт продукта

## Общие сведения
- **Название:** Сервис записи для бьюти-студии «Ноготочки»
- **Организация:** Бьюти-студия «Ноготочки» (ман licure, брови)
- **Версия:** 1.0.0
- **Дата создания:** 2026-09-27
- **Платформа:** Web (React + Vite), Backend (Node.js + Express + SQLite)

## Основные задачи сервиса
1. Регистрация и авторизация пользователей (клиенты, мастера, администратор)
2. Просмотр каталога услуг
3. Просмотр списка мастеров и их специализаций
4. Выбор услуги, мастера и времени для записи
5. Создание, просмотр, отмена и перенос записей
6. Административное управление: услуги, мастера, расписание, блокировки, записи

## Целевая аудитория
- Клиенты бьюти-студии (оформление записей)
- Мастера студии (просмотр своих записей, работа со своим расписанием)
- Администратор (управление всем сервисом)

## Техническая реализация
- **Frontend:** React 18 + Vite + TypeScript + React Router 7 + Tailwind CSS
- **Backend:** Node.js + Express + SQLite
- **База данных:** SQLite (файл booking.db)
- **Аутентификация:** токены (Bearer), bcrypt/scrypt для паролей

## Функциональные возможности

### Клиент
- Регистрация (email, имя, пароль — роль «client»)
- Вход/выход с токеном
- Просмотр своих записей
- Создание записи (выбор услуги → мастер → время)
- Отмена записи
- Перенос записи на другое время

### Мастер
- Вход с ролью «master»
- Просмотр своих записей
- Перенос/отмена записей (своих клиентов)

### Администратор
- Вход с ролью «admin»
- Управление услугами (CRUD)
- Управление мастерами (CRUD)
- Управление расписанием мастеров (по дням недели)
- Управление блокировками (создание/удаление)
- Просмотр всех записей
- Перенос/отмена записей (админ отменяет/переносит от имени клиента)
- Управление связями мастер-услуга

## База данных

### Таблицы
- **users** — пользователи (id, name, email, password_hash, password_salt, password_params, role, created_at, updated_at)
- **services** — услуги (id, name, description, duration_min, price, active)
- **masters** — мастеры (id, user_id, name, specialization, description, photo_url, work_start, work_end, active)
- **schedule** — расписание мастеров (id, master_id, day_of_week, work_start, work_end)
- **master_services** — связи мастер-услуга (id, master_id, service_id)
- **bookings** — записи (id, client_id, master_id, service_id, start_time, end_time, status, created_by, force_overlap, created_at)
- **blocks** — блокировки (id, master_id, start_time, end_time, reason)
- **tokens** — токены авторизации (id, user_id, token_hash, expires_at, created_at)

## Эндпоинты API

### Auth
- POST /api/auth/register — регистрация
- POST /api/auth/login — вход
- POST /api/auth/logout — выход
- GET /api/auth/me — текущий пользователь

### Services
- GET /api/services — список услуг
- GET /api/services/:id — услуга по ID

### Masters
- GET /api/masters — список мастеров (с serviceIds)
- GET /api/masters/:id — мастер по ID

### Availability
- GET /api/masters/:id/availability?date=&serviceId= — доступные слоты

### Bookings
- POST /api/bookings — создание записи
- GET /api/bookings — список записей (своих / всех для admin)
- GET /api/bookings/:id — запись по ID
- DELETE /api/bookings/:id — отмена записи
- PATCH /api/bookings/:id — перенос записи (изменение start/end) или изменение статуса

### Schedule
- GET /api/schedule — расписание всех мастеров
- GET /api/schedule/:masterId — расписание конкретного мастера

### Blocks
- GET /api/blocks — все блокировки
- GET /api/blocks/:masterId — блокировки мастера

### Admin
- GET /api/admin/bookings — все записи
- GET /api/admin/users — все пользователи
- GET /api/admin/masters — все мастера
- GET /api/admin/services — все услуги
- GET /api/admin/master-services — связи мастер-услуга
- POST /api/admin/master-services — создать связь
- DELETE /api/admin/master-services — удалить связь
- POST /api/admin/masters — создать мастера
- POST /api/admin/services — создать услугу
- POST /api/admin/schedule — создать/изменить расписание
- DELETE /api/admin/schedule/:id — удалить запись расписания
- POST /api/admin/blocks — создать блокировку
- DELETE /api/admin/blocks/:id — удалить блокировку

## Инсталляция и запуск
1. Клонировать репозиторий
2. Установить зависимости: `npm install`
3. Инициализировать БД: `node src/server.js` (схема создаётся автоматически)
4. Запустить сервер: `node src/server.js` (по умолчанию порт 3000)
5. Фронтенд: `cd frontend && npm run dev` (dev-режим, порт 5173) или `cd frontend && npm run build && npm run preview`
