### 2.2 Получение списка мастеров
- **Сценарий:** GET /api/masters
- **Ожидаемый результат:** статус 200, массив из 3 мастеров с serviceIds
- **Фактический результат:** (ожидается успешное получение)

### 2.3 Создание записи (полный путь)
- **Сценарий:**
  1. Выбрать услугу (например, "Маникюр с покрытием гель-лаком", ID 15)

- **Фактический результат:** (ожидается успешная отмена)

### 2.5 Перенос записи
